# LoreDesk downloads

Windows tester downloads for LoreDesk, an offline campaign notebook and spatial desk.

Download the installer, Getting started guide, and SHA256 checksums from [Releases](https://github.com/zaevansious/loredesk-downloads/releases).

Run the installer, then open LoreDesk Tester 0.22.1 from Start. A new installation begins with an empty notebook. Help is available inside the app and as a standalone HTML guide.

This is an unsigned tester preview. Windows, antivirus, or organization policy may warn or block it. Do not disable security protections. Local antivirus results do not guarantee safety or establish that another service's warning is a false positive.

Keep independent notebook backups. This preview is for Windows x64; touch, varied display scaling, and iPad compatibility are not certified.

This repository contains download information and release assets. App source code, personal notebooks, and internal testing reports are not included.
